inFAMOUS 2 DLC goes here.

Put your inFAMOUS 2 DLC unlock files (*.edat, for example unlock_kessler_skin.edat) here, in
this folder or in subfolders. Each time the game starts, the port copies the new ones to where
the game looks for them (game/dev_hdd0/game/<your game's ID>/USRDIR/dlc/ulf). The files you put
here are not changed, and you can leave them here.

Where the files are: once the DLC is installed on your PS3 or in RPCS3, they are in its
dev_hdd0/game/<your game's ID>/USRDIR/dlc/ulf folder (<your game's ID> is BCES01143, BCUS98125,
NPUA80638 ...). If RPCS3 is on this PC you need nothing here: Setup copies them by itself, on
install and on every update.

The DLC has to be for the same version (region) of the game as your copy. DLC that needs a
license file (.rap) is not supported yet.
